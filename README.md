# harshithraj.com portfolio

A responsive, single-page personal portfolio for Harshithraj.

## Preview locally

This project includes a zero-dependency local preview server. With Node.js installed, run:

```powershell
node server.js
```

Then open `http://localhost:4173` in a browser.

## Add the portrait

Place the supplied image at:

```
assets/harshithraj-portrait.jpg
```

The image is intentionally shown in an editorial, monochrome crop; the source image itself is never altered. Until it is added, the page shows a quiet HR fallback panel.

## Before publishing

Replace each bracketed placeholder and the marked “coming soon” areas with confirmed information. In particular, add the preferred contact method, location/availability, MCA institution and dates, resume file, and project links/case studies. No DNS or hosting configuration is included or changed.

## Deployment

Upload the folder to any static host (for example, GitHub Pages, Netlify, Cloudflare Pages, or Vercel) and configure the custom domain only after the hosting target is approved. The site is plain HTML/CSS/JavaScript, so it needs no build step.
